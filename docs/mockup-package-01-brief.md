# Mockup Package 01 — Cursos + Inscrição

## Objetivo

Criar o primeiro conjunto visual representativo da plataforma, usando a Home atual como baseline de identidade e validando o domínio prioritário: descoberta do curso → escolha da turma → inscrição.

## Entregas do primeiro ciclo

### 1. Cursos — desktop

Estrutura recomendada:

- header público já coerente com a Home;
- hero editorial curto, sem ocupar uma tela inteira;
- mensagem clara de gratuidade;
- filtros principais;
- cards de cursos/turmas;
- alternância opcional para grade semanal;
- destaque de status de inscrição;
- CTA “Inscreva-se” ou “Entrar na lista de espera”.

### 2. Cursos — mobile

Prioridades:

- filtros compactos e acessíveis;
- leitura rápida de dia/horário/idade;
- cards sem excesso de informação;
- CTA sempre claro;
- navegação sem depender de hover.

### 3. Curso individual

Conteúdo mínimo:

- nome;
- frente/categoria;
- descrição;
- fotografia real;
- gratuidade + materiais incluídos;
- horários/turmas disponíveis;
- faixa etária;
- local;
- status;
- requisitos quando existirem;
- CTA de inscrição.

### 4. Inscrição de menor — etapa crítica

Representar:

- dados do aluno;
- indicação clara de menoridade;
- dados do responsável;
- contatos;
- consentimentos obrigatórios;
- autorização de imagem separada quando aplicável;
- revisão antes do envio;
- linguagem humana, sem aparência de formulário burocrático estatal.

### 5. Confirmação

Representar:

- inscrição recebida;
- curso/turma escolhida;
- protocolo;
- explicação do próximo passo;
- informação de que aprovação/matrícula pode depender da regra do Instituto;
- canais de contato.

## Estados visuais a demonstrar no pacote

Pelo menos um exemplo de cada:

- inscrições abertas;
- últimas vagas;
- lista de espera;
- encerrada;
- turma em andamento.

## Linguagem visual

- off-white dominante;
- azul Fontes para orientação e ação;
- navy apenas onde trouxer estrutura/contraste;
- amarelo como sinal pontual;
- cards com forte hierarquia editorial, evitando aparência de marketplace;
- ondas/patterns como conectores e planos gráficos, sem cobrir rostos;
- fotografia real/duotone como elemento protagonista;
- tipografia Sora/DM Sans;
- cantos e superfícies coerentes com a Home, sem exagero de “cards SaaS”.

## O que não decidir por conta própria no mockup

Usar placeholders/configuração, sem inventar:

- número de vagas;
- critérios de aprovação;
- professor de cada turma;
- descrição oficial completa;
- faixa etária do Vôlei;
- datas/ciclos definitivos.

## Critério para avançar ao Pacote 02

O Pacote 01 deve estabelecer componentes reutilizáveis de:

- header/navegação;
- hero interno;
- filtro;
- card de curso;
- badge/status;
- bloco de informação;
- CTA;
- formulário;
- stepper/progresso;
- feedback de sucesso/erro;
- composição desktop/mobile.

Esses componentes visuais servirão de base para painel, Área do Aluno, Empresa e Apoiador.
